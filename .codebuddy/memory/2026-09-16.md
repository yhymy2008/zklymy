### 踩坑

1. **lucide-react 0.451.0 打包失败**：barrel 引用了不存在的 `dist/esm/icons/smile-plus.js`，dev 正常但 `vite build` 报 `Could not resolve`。解决：升级到 `^0.468.0`。
2. **ProtectedRoute 吞掉 children**：admin 路由写成 `<ProtectedRoute adminOnly><AdminLayout/></ProtectedRoute>` 但组件只 `return <Outlet/>`，AdminLayout 不渲染。修复：`return children ? <>{children}</> : <Outlet />`。
3. **seed 与运行中的 server 冲突**：server 在内存持有 db，seed 写文件后会被覆盖。顺序应为：停 4000 → `node server/seed.js --force` → 重启 4000。
4. `jsx: react-jsx` 下必须 `import type { FormEvent, ReactNode } from 'react'`，否则 TS2749/TS2322。
