# 2026-08-28

- 修复 `Import "openpyxl" could not be resolved from source`：根因是工作区 `.venv` 虚拟环境（Python 3.12.10）未安装 openpyxl，而 IDE 使用该虚拟环境做分析（系统 python3.9 有 openpyxl 但 IDE 不认）。已在 `.venv` 中执行 `pip install openpyxl`（3.1.5）解决。
- 环境关键点：IDE 默认解释器配置为 `python.defaultInterpreterPath` = `WindowsApps\python3.12.exe`，但工作区存在 `.venv`（Python 3.12.10）优先被使用；后续 Python 依赖需装到 `.venv` 而不是系统 python。
