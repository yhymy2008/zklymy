- 完成任务：编写 Excel 指定列 MD5 加密脚本 `md5_excel.py`（位于工作区根目录）
  - 功能：读取 .xlsx/.xlsm，对指定列每行计算 MD5（UTF-8 hexdigest），写入目标列（自动追加到表尾或复用已有列），保留原格式
  - 源列支持三种写法：表头名称（如 "手机号"）、列字母（"B"）、列序号（1-based）
  - 用法示例：`python md5_excel.py -i data.xlsx -c 手机号 -t md5_hash`
  - 默认另存为 `原文件名_md5.xlsx`，`--overwrite` 可直接覆盖原文件
  - 依赖：openpyxl（已安装到当前 Python 环境）

  - 依赖：openpyxl；已用测试数据验证：4 条 A 记录匹配 3 条、未匹配留空、数字字符串归一化匹配正常
  - 用法示例：`python lookup_merge.py -a data.csv -b base.xlsx -ak 手机号 -bk 手机号`
