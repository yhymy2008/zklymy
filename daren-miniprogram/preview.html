01 / MINI PROGRAM SPEC

小程序界面规范与适配要点

小程序与 H5 的关键差异集中在导航栏、胶囊按钮、tabBar 与安全区。以下尺寸单位已按 750rpx = 375pt 换算。

导航栏与胶囊

导航栏高度44pt / 88rpx
状态栏高度44pt（刘海屏）
胶囊按钮87 × 32pt
胶囊右边距7pt

胶囊区域为系统占位，标题居中需预留左右各 95pt，避免与胶囊重叠。深色导航栏用 navigationBarTextStyle: white。

tabBar 与安全区

tabBar 高度50pt / 100rpx
底部安全区+34pt
图标尺寸81 × 81rpx
最多 Tab 数5 个

原生 tabBar 不支持凸起中心按钮；若要做「推广」凸起按钮，需改用 custom-tab-bar 自定义组件（本方案用原生平铺 5 Tab，选中态品牌紫）。

转发与分享能力

转发给好友/群onShareAppMessage
分享到朋友圈onShareTimeline
按钮触发open-type="share"
携带参数path + query

素材转发走自定义半屏面板：好友/群用原生转发，朋友圈用 canvas 生成海报 + 保存相册，文案用 setClipboardData。

交互与性能约束

页面栈上限10 层
设计基准750rpx 栅格
触控热区≥ 44pt
setData 单次≤ 256KB

长列表用 recycle-view / 分页加载；海报生成放 canvas 2d 并加 loading；二维码用服务端下发图片，避免前端生成。

04 / KEY IMPLEMENTATION

核心能力的小程序实现要点

设计与实现的关键衔接点：分销参数如何随转发传递、海报如何生成、关系如何绑定。

转发携带分销参数

在分享路径里带上达人 ID，好友打开即完成归因，无需填写邀请码。

onShareAppMessage() {
  const sid = getApp().globalData.sid  // 8823
  return {
    title: '孩子写作业拖拉？3 个方法',
    path: `/pages/asset/asset?id=A102&sid=${sid}`,
    imageUrl: this.data.cover
  }
}

扫码绑定关系

小程序码写入 scene，进入时解析并上报绑定，配合服务端 30 天锁客。

onLoad(query) {
  if (query.scene) {
    const s = decodeURIComponent(query.scene)
    // scene=sid_8823
    const sid = s.split('_')[1]
    bindDistributor(sid)
  }
  if (query.sid) bindDistributor(query.sid)
}

canvas 生成专属海报

用 canvas 2d 绘制模板 + 小程序码，导出临时文件后保存到相册。

wx.canvasToTempFilePath({
  canvas, destWidth: 750, destHeight: 1000,
  success: res => wx.saveImageToPhotosAlbum({
    filePath: res.tempFilePath
  })
})
